厚生局が公表する医科の医療機関データを、地域・名称・病床数などで検索し、ExcelやCSVで出力できます。

1. ログイン

  1. システムを開き、管理者から案内されたメールアドレスとパスワードを入力します。
  2. 「ログイン」を押します。
  3. 仮パスワードの場合は「パスワード変更」を開き、新しいパスワードを設定してください。12文字以上・72バイト以下で、確認欄にも同じ内容を入力します。

ログインできない場合は入力内容と利用承認の状態を管理者に確認してください。通信状況はログイン画面の「接続を確認」で確認できます。利用後は画面右上の「ログアウト」を押します。

2. 医療機関の検索（病院・診療所）

  1. 「医療機関検索」を開き、「医療機関区分」で「病院」または「診療所」を選びます。
  2. 必要な条件を入力します。複数の条件を指定すると、すべての条件に一致する施設を検索します。
  3. 「この条件で検索」を押します。
  4. 件数と一覧を確認します。「前へ」「次へ」でページを移動し、「並べ替え」と昇順・降順で表示順を変更できます。
検索項目指定方法
厚生局・都道府県地域を選択します。都道府県はCtrlキー（Macは⌘キー）を押しながら複数選択できます。地域を限定しない場合は選択しません。
市区町村・医療機関名・開設者名称の一部で検索できます。
医療機関コード登録されている10桁の数字を入力します（完全一致）。
開設主体医療法人などを選択します。
診療所の病床診療所を検索するときに「有床」または「無床」で絞り込めます。
病床種別・病床数総病床数・一般病床・療養病床などを選び、下限・上限を指定します。制限しない場合は下限・上限を空欄にします。
精神科病院分類精神病床のみ、混合型などで絞り込めます。

病院検索は初期状態で20〜200床に限定されています。すべての規模の病院を探す場合は、病床数の下限・上限を両方空欄にしてください。「診療所」を選ぶと病床数の下限・上限は空欄になります。

例：東京都の病院を規模に関係なく探す場合は、「病院」→「東京都」→病床数の下限・上限を空欄→「この条件で検索」の順に操作します。

通常は現存施設のみが対象です。必要に応じて「休止施設も含める」を選んで検索してください。廃止・辞退・取消・確認中の施設は通常の検索・出力に含まれません。元資料に病床数の記載がない場合は0床として扱います。

条件を変更した後は再度「この条件で検索」を押してください。「条件をリセット」で初期条件に戻せます。

3. 医療機関データをExcel・CSVへ出力

  1. 検索条件を設定して「この条件で検索」を押し、出力する対象を確認します。
  2. 検索結果の右上にある「Excel」または「CSV」を押します。
  3. 生成が終わるまで待ち、ダウンロードされたファイルを保存します。出力対象は表示中のページだけでなく、直近の検索条件に一致する全件です。
ボタン内容・用途
Excel「検索結果.xlsx」を出力します。病院・診療所・精神科病院のシート、集計、取得元・更新情報などを確認できます。精神科病院シートは病院シートの一部を再掲しています。
CSV「検索結果.csv」を出力します。検索対象の医療機関を、医療機関コード・名称・住所・病床数などの日本語の見出しで出力します。
全取得県マスター検索条件に関係なく、収録済みの全都道府県の現存施設を「全国医療機関マスター.xlsx」に出力します。管理者向けの全状態・全項目のCSVとは対象範囲が異なります。

CSVはUTF-8（BOM付き）です。Excelに取り込む場合は「データ」→「テキストまたはCSVから」を使い、医療機関コードと電話番号を文字列として指定すると先頭の0を保持できます。通常のCSV出力では表計算の数式として扱われ得る文字列の先頭にアポストロフィが付く場合があります。

施設情報の基準日は「取得元・更新情報」を確認してください。出力前に条件を変更した場合は、必ずもう一度検索してください。

4. 全データ出力（管理者向け）

管理者・マスターが利用できます。一般ユーザー（閲覧者）にはボタンが無効状態で表示されます。

  1. 管理者アカウントでログインし、「医療機関検索」を開きます。
  2. 検索結果欄の「全医療機関データ出力（CSV）」を押します。事前の検索は不要です。
  3. 取得・生成が終わるまで待ち、「全医療機関データ.csv」を保存します。件数が多いため通常の検索出力より時間がかかります。
  4. 取り込み先のシステムで各列を対応付けてインポートしてください。
  • 検索条件に関係なく、DBに登録済みの病院・診療所の全件、全状態、全項目を出力します。廃止などの施設も含むため、現存施設だけが必要な場合は取り込み先でstatusが「現存」の行に絞ってください。
  • UTF-8（BOM付き）CSVで、見出しはcode、name、statusなどのDB項目名です。JSON項目はJSON文字列、空値は空欄で出力します。
  • 医療機関コードなどの文字列は元の値を保持します。コードや電話番号を数値に変換しないよう、取り込み先では文字列型を指定してください。
  • 医療機関データの出力機能です。利用者情報やアクセスログは含みません。

5. ユーザー追加（管理者向け）

  1. 管理者アカウントでログインし、「利用者管理」を開きます。
  2. 「ユーザーを追加」の「メールアドレス（ID）」に利用者のメールアドレスを入力します。
  3. 「仮パスワード」を入力するか、「仮パスワードを自動生成」を押します。パスワードは12文字以上・72バイト以下にします。
  4. 権限を選択します。通常の利用者は「閲覧者」、ユーザー管理や全データ出力を担当する方は「管理者」を選びます。
  5. 「ユーザーを追加」を押し、完了メッセージを確認します。
  6. 表示される「送付用メモ」を「メモをコピー」または「テキスト保存」で控え、対象者にログイン案内を渡してください。メールは自動送信されません。
  7. 対象者に初回ログインと「パスワード変更」を依頼してください。

送付用メモには仮パスワードが含まれます。画面を離れる前に控え、対象者だけに案内してください。

追加後の承認状態や権限は利用者一覧で変更し、「保存」を押します。利用を止める場合は「利用を承認」のチェックを外して保存してください。自分自身とマスターの権限・承認状態はこの画面から変更できません。

本書は2026年10月16日時点の操作画面に対応しています。データの収集範囲・基準日はシステムの「取得元・更新情報」でご確認ください。
