# 医療施設動態調査との照合

添付`geppou0807.xlsx`の令和8(2026)年7月を比較元にしました。一般診療所105,702件に対し、当システムの現存診療所は88,799件、差16,903件です。病院は7,942件対7,931件、差11件です。

[県別の数値とコード監査](statistical-reconciliation.json)に記録しています。7桁重複・同名削除・取得済み主一覧内部の行落ち・表示だけの誤りは検証結果から否定しました。

対象範囲の相違を確認しました。DBは保険医療機関の通常医科主一覧に限定します。差の全件を非保険施設の確定数や取込漏れ件数とは扱いません。[対象範囲の根拠](survey-scope.md)を参照してください。
