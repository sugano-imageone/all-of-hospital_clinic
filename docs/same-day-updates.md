# 都道府県単位の同日更新

目標は、公式資料が利用可能になった更新日に24時間以内で対象県の更新を終えることです。
外部資料の未公表、未対応の表形式、資格情報やDBの障害がある場合に完了を保証するものではありません。

## 処理単位と順序

厚生局のファイルを取得・検証した後、担当県を県別ファイルへ分割し、全厚生局共通のキューへ入れます。
通常の主一覧47県97,457件では、初期順は東京都13,960、大阪府8,875、神奈川県6,831、
愛知県5,215、兵庫県5,028、福岡県4,537、埼玉県4,362、千葉県3,724件などです。
過去3回の県別成功実測から遅い側の1件あたり時間を求め、1.5倍の余裕と通信回数を加えて順序を更新します。
初期値は1件0.025秒です。重複スキップの時間を通常更新の実測には使いません。

DBへの書込みは1本です。小さい県を先に完了させるために大きい県を最後まで放置したり、
多数の書込みを同時実行して小さいDBへ負荷を集中させたりしません。
初回試行が失敗した県は、未着手の県を処理した後で、最大3回まで同日中に再試行します。
認証拒否や入力検証エラーは同じ条件で自動再試行しません。

## 小分け送信と一括確定

`sql/013_staged_upload.sql` は、Supabaseの安全更新チェックに対応した012の修正と、管理用の一時保管RPCを含みます。
012を適用済みでも、013の全文をSQL Editorで実行します。011のサービスロール90秒設定も必要です。
本番APIキーにはSQL関数を変更する機能がありません。

200件超またはJSONが約508KiB超の県は、最大200件かつ約508KiB以下の単位で送信します。
一時保管はservice_role専用で、一般利用者にはテーブル・RPCともアクセス権がありません。
すべての送信がそろい、県・基準日・ファイル・件数を検証してから、DB内で結合して一括登録します。
途中の送信で止まっても現行マスターは変わりません。最後の登録に失敗した場合も全体がロールバックされます。
同じ送信は再開でき、同じ公表ファイルとパーサーの成功済みデータは再登録しません。
完了時に一時データを削除し、未完了の古い保管は翌日以降の開始時に回収します。

## 時間予算と再開

- 1実行は取得・解析を含む5時間30分予算。Actionsの強制終了は5時間55分。
- JST20〜25日の毎時起動を設定。日付外の起動はワーカー側で終了。
- JSTの翌日0時を越えて処理を開始しないよう、日内予算を短縮。送信・確定の各段階でも残り時間を検査。
- 県別結果を1件ずつ `update_jobs` に保存。成功した取込の識別情報は `source_imports` にも残るため、ジョブ再開時に二重登録しない。
- `artifacts/monthly.json` に県別順序、予測時間、実測時間、試行回数、未完了県、進捗保存エラーを出力。
- 失敗・未完了・進捗保存失敗があれば終了コード1。GitHub Actionsで失敗と成果物を確認可能。

初期モデルの試算は初回約81分、最大3回の試行と取得・解析30分の余裕を含め約4時間33分です。
これはモデル値で、本番での全47県同日更新を実証した値ではありません。
県別の基準件数と予測は [update-capacity.json](update-capacity.json) にあります。

```bash
python -m app.importers.planning --directory data/national
python -m app.importers.monthly --apply --budget-seconds 19800 --max-attempts 3
```

定期実行はまだ無効です。GitHubの認証情報設定と本番所要時間の受入確認後に有効化します。
形式未対応の厚生局は、通常一覧だけを成功扱いにせず、既存データを維持して未完了として報告します。

診療所の件数差を踏まえ、処理容量の見積もりは約13万施設まで拡張しました。
現在の県別比率で約130,026件に増やした場合、3回の試行と取得・解析30分の余裕を含め約5時間51分というモデル値です。
13万件時の全3回試行は5時間30分の単一実行予算を超えます。残り時間の検査で未完了県を保存し、同日中の後続実行で再開します。現行97,457件の3回モデルは単一予算内です。
この容量見積もりは、未収録施設の取得・網羅性を確認したことを意味しません。

## 保険医科主一覧の受入範囲

2026-10-15に全47県の公式PDF・Excel・本番DBの97,457コードが一致しました。医科併設別表29行は歯科主一覧との対応を確認し、医科主一覧に独立施設として加算せず除外メタデータを更新レポートへ記録します。

全8厚生局の実配布物を再取得する月次dry runで、47県・97,457件の検証と県別キュー処理が成功しました（141.8秒、DB書込なし）。この計測は取得・解析・計画の検証であり、全国の新月データを本番へ全件登録する実測時間ではありません。定期実行はまだ無効です。
