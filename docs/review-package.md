# 社内レビュー用パッケージ

`python -m scripts.build_review` で、検証済みの主一覧と本番登録状況から説明用ファイルを生成します。
生成物は `artifacts/上司確認用/` と `artifacts/上司確認用パッケージ.zip` で、Gitには含めません。
APIキー、Authの利用者、セッション、パーサーの生の個票はパッケージへ出力しません。

- `はじめに.html`：確認範囲、デモ手順、本番の進捗、同日更新の設計、残課題。
- `検索デモ.html`：本番と同じ画面部品を使ったオフライン検索・集計・CSV出力。
- `全国医療機関マスター.xlsx`：現存96,730件、病院・診療所など6シート。
- `上司向け説明.pdf` と各画面PNG：ブラウザで確認後に出力した資料。

ZIPをすべて展開し、ChromeまたはEdgeで `はじめに.html` を開きます。
デモは公開Webホスティングや本番ログインの代用ではありません。デモ画面に対象範囲を常時表示します。
病床数20〜200、福岡県の病院302件、50件表示、次ページ、CSV302件、ダッシュボード96,730件をChromiumで確認しました。
モバイル390px幅とPDF出力も確認し、JavaScriptエラーは0件でした。
ExcelのMicrosoft 365動的配列数式の再計算は未検証です。データシートの通常フィルターを利用できます。

`病床情報の要確認一覧.csv`は0件。個別判定により自衛隊入間病院は名称を保持し、診療所・有床2床・現存にしています。
