# 診療所件数の差の調査（未解決）

添付された2026年7月の医療施設動態調査では一般診療所105,702件。当DBの2026年10月1日基準の現存診療所は88,057件で、差は17,645件（16.69%）です。病院は7,942件に対し7,902件、差40件です。以前の「11万件」という目安は比較基準に使いません。

表示だけの問題ではありません。全国の全診療所を網羅した完成版とは扱いません。

[調査結果と一次資料](statistical-reconciliation.md)、[47県の比較数値](statistical-reconciliation.json)を参照してください。

- 取得済み主一覧の元Excel施設行97,457行と解析件数が一致しました。
- 本番DBの全10桁コード集合と主一覧のコード集合が一致し、欠落0件です。
- 7桁・名称での重複排除はしていません。末尾7桁が同じ施設も別々に保持されています。
- 休止・確認中を仮に全加算しても診療所89,502件、差16,200件が残ります。
- 関東信越・東北の医科側歯科併設一覧744件は主一覧に全件収録済みです。
- 関東信越厚生局の事業年報でも保険指定医科診療所は33,749施設と公表され、同地域の動態調査40,291件より少ないことを確認しました。ただし基準日相違があり、全国の差の原因と件数は未確定です。

所有・開設者の分類差や数か月の時点差だけで、17,645件の全差を説明済みとはしません。別配布物の扱い、保険指定一覧と動態調査の対象範囲を施設単位で照合します。
