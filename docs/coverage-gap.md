# 動態調査との件数差と収録範囲

収録対象は、ユーザー指定により厚生局の保険医療機関・通常医科主一覧とします。非保険の届出医療機関は追加しません。

医療施設動態調査は医療法上の届出を基に集計され、保険指定を対象条件としていません。[調査対象・集計方法の原文確認](survey-scope.md)を記録しました。

2026年7月の一般診療所105,702件と、2026年10月1日のDB現存診療所88,057件との差17,645件は、異なる母集団・基準日の比較です。取込漏れや、非保険施設の確定件数とは扱いません。[約1.7万件の参考試算と限界](noninsured-reference-estimate.md)も参照してください。

厚生局の47県公式PDFとExcelは97,457コードで一致し、本番DBとも全コードが一致しました。[公式PDF照合](official-pdf-code-audit.json)・[本番DB照合](prefecture-live-verification.json)。

通常の検索・集計対象は現存95,959件（病院7,902、診療所88,057）。原資料の休止716件と、分類・表記の確認中782件もDBに保持し、通常集計と区別します。病床数不明の診療所80,732件は総数に含まれています。
