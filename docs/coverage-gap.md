# 診療所件数の差の調査（未解決）

2026-10-01基準の厚生局医科主一覧をローカル解析した現存施設は、病院7,902、診療所88,057件です。
ユーザーから提示された診療所約110,000件という目安との差は21,943件です。
この差を説明・照合できるまで、全国の全診療所を網羅した完成版とは扱いません。
県別内訳は [coverage-audit.json](coverage-audit.json) にあります。

## 確認できたこと

- 元の依頼範囲は「全国47都道府県の保険医療機関（医科）」で、10桁の保険医療機関コードを主キー候補としています。
- 九州厚生局の公式ページは「コード内容別医療機関一覧表（指定一覧）」で、保険医療機関・保険薬局の指定状況の配下にあります。
- 指定一覧と一般診療所総数では母集団が異なる可能性があります。ただし、この可能性だけで21,943件すべての差を説明済みとはしません。
- 病床数不明でも現存診療所として80,732件を収録しています。空欄の病床数を一律に検索対象外の施設として捨てているわけではありません。
- 診療所は現存88,057、休止695、確認中750件。休止・確認中を含めても89,502件で、目安との差は20,498件残ります。
- 北海道の原シートで医科区分の全3,250行を独立に数え、全行が解析結果と対応することを確認しました。
- その他の通常医科アダプターは施設連番1〜最終番号の欠落・重複を検査します。配布物・別表の選定漏れを保証する検査ではありません。
- 近畿の医科併設別表29件などの確認が残っています。29件だけで約2万件の差は埋まりません。

## 次の照合

1. 一般診療所全数と保険指定診療所数の公式統計を、基準日・定義をそろえて確認。
2. 各県の原資料件数と解析件数、別配布物・併設施設の有無を照合。
3. 差を「対象範囲の違い」「取得・解析漏れ」「状態・基準日の違い」に分けて件数化。
4. 保険指定のない施設まで対象にする場合は、医療情報ネット等の一次資料との追加照合と、保険コードを持たない施設の識別設計が必要。コードの捏造や仮の10桁コードで件数を埋めることはしない。

厚労省統計・e-Stat・医療情報ネットへの接続は、クラウド環境のネットワーク設定の公開待ちです。
既存の厚生局・Supabase・GitHubへの接続は維持しています。
