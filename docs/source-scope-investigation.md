# 公表範囲の追加調査



[関東信越厚生局・令和7年度事業年報](https://kouseikyoku.mhlw.go.jp/kantoshinetsu/000498885.pdf#page=83)の冊子75頁（PDF83頁）は、2026年3月末の保険指定医科診療所を **33,749施設** と公表しています。同地域の当DBは2026年10月1日で33,864件、添付の動態調査は2026年7月末で40,291件です。

公式の保険指定診療所数自体にも動態調査との大きな差があるため、比較母集団の差を調べる根拠になります。基準日が異なるので、この差6,542件を全国の不足原因へそのまま割り当てません。[出典・原文・SHA-256](insured-count-control.json)を保存しました。開設者が同じだから掲載／未掲載と判断することもしません。

関東信越の「医科（歯科併設）」529件、東北の「歯科併設」215件は、10桁医科コードで主一覧に全件収録済みでした。計744件を加算すると重複になります。[別配布物のコード照合](supplemental-source-audit.json)に記録しました。

歯科側の「医科併設」は関東43行・東北3行、既取得の近畿29行もあります。医科の独立施設として追加できるか、主コード／括弧コードと指定の関係の確認が残ります。歯科側のコードへ医科の接頭辞を付けて件数を埋めることはしません。

## 調査の残り

厚労省本体・e-Stat・医療情報ネットは現在の実行環境の接続許可に未反映です。追加先を含む設定案は保存済みですが、環境設定での公開が必要です。接続後は統計の対象定義と施設単位の一次資料を取得し、未収録施設の具体例と件数を確認します。全国の差の全要因は未特定のままです。

## 病床数不明の扱いを本番DBで再検証

病床数NULLの施設が通常集計から落ちていないか、本番DBへ条件別の件数問い合わせを実行しました。

| 現存診療所 | 本番DB件数 |
| --- | ---: |
| 総数 | 88,057 |
| 総病床数NULL（北海道以外） | 80,732 |
| 総病床数が判明 | 7,325 |
| 上記のうち0床 | 2,437 |

80,732 + 7,325 = 88,057であり、病床数不明は診療所総数に含まれています。通常の病院／診療所区分は原資料の明示区分を保持し、病床が空欄という理由だけで診療所から除外していません。施設区分自体がNULLなのは全DBで2件、現存には0件です。

北海道以外の病床数NULLを0に変更しても、診療所総数88,057件は増えません。一方、明示的な「無床」や病床数範囲の検索ではNULLが除外されるため、これらの条件付き検索の件数には影響します。画面では診療所へ切り替えた際に病床数の上下限を空欄へ戻す処理も確認しました。

[本番DBの条件別件数と確認時刻](blank-bed-live-audit.json)を保存しました。この確認ではDBの病床値や分類を変更していません。
