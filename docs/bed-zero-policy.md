# 病床数の未記載を0に統一（2026-10-15）

ユーザーの明示指定により、一般・療養・精神・結核・感染症の未記載項目を全国で0床として保存します。総病床数は読めた各病床種別を合算し、全種別未記載は0床です。北海道の元資料に総病床数だけがある場合は、その総数を維持して未記載の種別だけ0にします。

元資料の空欄・文字・数値・行番号はrawに保持します。青森県の末尾にある大量の空行は開始・終了行の範囲で記録し、元の空行へ完全に復元できることを確認しています。名称・住所・電話などの未記載を0にする処理ではありません。

改行された「一般(特例)」「特定」「介護」「感II」の数値は、直前の病床種別または感染症へ集約してから総数を計算します。これらは未記載ではないため、0にはしません。

全97,457件・6種類の病床数でNULLは0件です。全コード・名称・掲載状態・原行が補正前と一致し、DBの施設区分・病床数・有床無床・精神病床分類を入力と全件照合しました。

病床全種別が未記載で原区分が病院だった2施設は、0床・診療所として再計算しています。元区分と変更理由はrawに保持します。自衛隊入間病院は名称を保持したまま診療所・有床2床・現存です。

現存96,730件（病院7,931・診療所88,799）、休止727件です。施設の増減ではなく分類・データ解釈の補正として記録しています。
