# 都道府県別の実DB照合

比較元は添付Excelの第3表「都道府県別にみた施設数及び病床数」です。47県の統計合計が全国値（一般診療所105,702、病院7,942）と一致することを確認しました。

本番DBの全97,457件を読み取り、コード・県・施設区分・状態が解析結果と全件一致しました。直前の照合結果を再利用する場合は検証時刻と入力指紋を確認しています。基準日は原資料メタデータです。以下のDB件数は現存のみです。統計は2026年7月末、DB資料は2026年10月1日であり、同一時点の比較ではありません。

**47県すべてで現存診療所数が統計を下回ります。差の合計は16,905件です。** 動態調査は保険指定のない施設も対象に含み得るため、差を取込漏れ件数や非保険施設の確定数とは扱いません。

## 調査への使い方

東京都など差の絶対数が多い県と、差率が大きい県を並行して調べます。県別の公表保険指定数、補足一覧、施設単位の名簿を比較し、全国共通の対象範囲の違いと地域別の取得漏れを区別します。順位だけで原因を断定しません。

休止・確認中を仮に全加算した場合の差もCSVに残しています。現存と認定した数ではありません。
