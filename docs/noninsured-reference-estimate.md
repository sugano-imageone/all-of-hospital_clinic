# 保険指定のない診療所数の参考試算

**全国約1.7万件という粗い目安は得られます。ただし、全国の非保険施設を集計した実数ではありません。**

| 使用した公表数値 | 基準日 | 診療所数 |
| --- | --- | ---: |
| 関東信越10都県の一般診療所（動態調査） | 2026年7月末 | 40,291 |
| 同地域の保険指定医科診療所（厚生局事業年報） | 2026年3月末 | 33,749 |
| 全国の一般診療所（動態調査） | 2026年7月末 | 105,702 |

地域の差は6,542件、一般診療所総数に対して約16.24%です。

`105,702 × (40,291 − 33,749) ÷ 40,291 ≒ 17,163`

地域の差率を全国へ単純に当てはめた参考値です。計算に当DBの件数は使用していません。当DBの現存診療所数との差16,905件は、試算との規模比較にだけ用います。

出典：[関東信越厚生局 令和7年度事業年報・冊子75頁／PDF83頁](https://kouseikyoku.mhlw.go.jp/kantoshinetsu/000498885.pdf#page=83)、ユーザー提供の `geppou0807.xlsx` 第3表。事業年報の公表保険指定数は独立に取得し、原文・ファイルSHA-256を[記録](insured-count-control.json)しています。

## 読み取りの限界

- 時点が4か月異なるため、6,542件を同一時点の非保険診療所実数とは断定しません。
- 関東信越の割合を全国へ当てはめた値であり、地域差を反映していません。
- 休止等の扱いを完全に統一した比較ではありません。
- 病院・歯科診療所はこの推計に含みません。
- 差の全てを美容・健診専用施設とみなしません。保険指定を受けた美容・健診実施施設もあります。

**「非保険診療所が1万数千件規模で存在する可能性と今回の差の規模は整合する」と読むための試算です。16,905件すべての理由を検証済みとする根拠にはしません。**

全国実数に近づける次の資料は、医療施設静態調査の「社会保険診療等の状況」の集計です。これが取得できれば、保険指定の有無と実際の社会保険診療実施の有無の定義を確認した上で、同一時点の総数と比較します。現時点でその全国表の数値は未取得です。
